# Critical-value verification set (held out)

Synthetic, held-out set for measuring critical-value recall with a meaningful interval
(the 30 frozen eval cases contain only 2 critical rows). **It is never used to tune
thresholds, prompts or models**; `tests/test_critical_set.py` fails if tuning code
references it. Everything here is fictional; every PDF carries the synthetic-test-report line.

Generated by `scripts/generate_critical_set.py` (deterministic; `--out` to relocate) and
scored by `evals/critical_eval.py` -> `evals/results_critical.json`.

## Contents
- `rows.json`: 312 single-test rows (196 critical) with `expected_flag`,
  `expected_is_critical`, `expected_rule` (`R1_critical` or `not_R1`). Labels are computed with
  exact decimals from `reference/panels.yaml` critical limits (canonical units) and unit factors.
- `reports/C01-C10.pdf` + `ground_truth/C01-C10.json`: 10 report PDFs (layouts A-D, canonical,
  lakhs/cumm and /cumm units, missing range, comparator), each with at least one critical value.

## Row categories
| category | rows | what it covers |
|---|---|---|
| boundary_canonical | 45 | each limit: one step past, fine step past, at, fine step inside, one step inside |
| boundary_alt_unit | 50 | same, PLT in lakhs/cumm, lakh/cumm, /cumm, cells/cumm, /ul |
| unit_equivalent_spelling | 42 | PLT canonical-unit spellings (10^9/L, thou/cumm, ...) past/at/inside |
| misleading_printed_range | 35 | critical values inside a wide printed range (look normal) |
| no_or_normal_printed_flag | 36 | critical values with no printed flag or a printed "N" |
| no_printed_range | 18 | critical values with no printed range |
| comparator_critical | 22 | "<" / ">" values at or beyond a limit |
| comparator_control | 18 | "<" / ">" values that cannot be shown to be critical |
| control_abnormal_noncritical | 18 | abnormal but short of the critical limit |
| control_normal | 18 | normal values for each test with critical limits |
| control_no_critical_limit | 10 | extreme values on tests without critical limits |
